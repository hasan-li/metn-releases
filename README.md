# Metn

Metn is a native macOS Markdown editor for local files and folders.

## Download

The current release is **Metn 1.1.0** for macOS 13 or later.

[Download Metn 1.1.0](https://github.com/hasan-li/metn-releases/releases/latest/download/Metn-1.1.0.dmg)

Every published DMG is signed with a Developer ID certificate, notarized by Apple, and stapled before publication.

## Install

1. Download the DMG from the Releases page.
2. Open it and drag **Metn** to **Applications**.
3. Open Metn from Applications.

Release notes accompany each [GitHub release](https://github.com/hasan-li/metn-releases/releases).

## Bug reports

[Open a bug report](https://github.com/hasan-li/metn-releases/issues/new?template=bug-report.yml). Do not include private notes or files.

This repository distributes releases and accepts bug reports. Metn's source repository is private.
